Features
1. MAIN DASHBOARD — PERSONAL AUDIT COMMAND CENTER
 Core Features:
Summary counts: documents uploaded, interviews added, controls analyzed.
Compliance overview showing Annex A controls categorized as: compliant, partially compliant, non-compliant.
Quick links: add new document, upload interview, view SOA draft.
Recommended Add-ons
AI-generated compliance score (0–100).
Gap summary showing missing or weak controls.
Recent activity timeline showing latest user actions.


2. DOCUMENT DASHBOARD — DOCUMENT ANALYSIS HUB
 Core Features:
Upload and store documents.
AI summaries: short summary, detailed summary, and ISO 27001 compliance-focused summary.
Annex A mapping that lists which controls the document supports.
Document-specific gap analysis highlighting missing or incomplete policy content.
Simple workflow: Raw → Analyzed → Verified.
Optional Add-ons:
Highlight extraction (key sentences used for Annex A mapping).
Version comparison (diff viewer for updated documents).


3. INTERVIEW DASHBOARD — QUALITATIVE EVIDENCE COLLECTOR
 Core Features:
Store respondent information: name, role, division.
Question list: standard ISO 27001 interview questions + custom questions.
Input interview answers manually or by pasting transcripts.
AI functions: interview summary, key statement extraction, Annex A mapping, contradiction detection, and maturity score (0–5).
4. ANNEX A CONTROL NAVIGATOR — ISO 27001 CONTROL BROWSER
 Core Features:
Display all 93 Annex A controls.
Each control page includes: related documents, related interviews, AI compliance rating, explanation of status, and suggested improvement actions.
5. AI-GENERATED STATEMENT OF APPLICABILITY (SOA GENERATOR)
 Core Features:
Generate a draft SOA automatically.
AI fills fields such as: applicability, rationale, implementation status, and recommendations, based on combined evidence from documents and interviews.
6. GAP ANALYSIS AND RECOMMENDATIONS MODULE
 Core Features:
Ranked list of missing or weak controls.
For each gap: problem summary, supporting evidence, AI recommendation, and priority level (Low, Medium, High).

Interface UI
UI STYLE REQUIREMENTS FOR “NovaTrix”
Design an interface for a system called NovaTrix.
 The visual direction should follow these principles:
Simple and Futuristic


Prioritize clean layout, minimal noise, and high readability.


Avoid over-decorated elements, gradients, or heavy shadows.


Use subtle geometric shapes, smooth spacing, and balanced proportions to create a modern futuristic tone without looking like sci-fi clichés.


Color Palette


Primary: white (#FFFFFF) for background and main surfaces.


Accent: cyan / aqua (#00FFFF) for highlights, indicators, active states, and small interface elements.


Neutral grays can be used for typography hierarchy and separators (e.g., #222, #444, #888), but they should not overpower the accent.


Non-Template, Non-AI-Generated Look


Avoid the common “AI UI” look (glows, neumorphism, excessive blur).


Avoid generic dashboard templates.


Typography hierarchy must feel intentional and human-driven, using clean sans-serif typefaces with precise spacing.


Components should look engineered, not ornamental: crisp lines, clear spacing, functional shapes, and predictable behavior.


Ensure the design feels original: build from atomic design principles rather than borrowed UI kits.


Branding as “NovaTrix”


The brand identity should communicate clarity, intelligence, and precision.


The logo or title “NovaTrix” should be placed cleanly, with straightforward typography (no sci-fi fonts).


The accent (#00FFFF) may be integrated subtly into the logotype (such as dot, underline, or stroke).


Overall Tone


Efficient, professional, forward-looking.


Aesthetic should emphasize utility with elegance, not decoration.


Use whitespace and grid alignment heavily so the interface looks deliberate, calm, and modern.
